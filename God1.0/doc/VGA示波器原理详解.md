## 第一课：这个项目是做什么的？

### 背景：什么是桩基检测？

```
地面上：
┌─────────────────────────────────────────────────────────────┐
│                        建筑物                                │
│                          ▲                                   │
│                          │                                   │
│                    ┌─────┴─────┐                            │
│                    │   桩帽    │                            │
│                    └─────┬─────┘                            │
└──────────────────────────┼──────────────────────────────────┘
                           │
═══════════════════════════╪═════════════════════════════════
                      地面 │
                           │
                    ┌──────┴──────┐
                    │             │
                    │    桩身     │  ← 这根柱子可能有问题！
                    │   (混凝土)  │    - 有裂缝吗？
                    │             │    - 有缩颈吗？（变细了）
                    │             │    - 有扩颈吗？（变粗了）
                    │             │    - 桩底有问题吗？
                    │             │
                    └──────┬──────┘
                           │
                      桩底 ▼
                    ┌──────┴──────┐
                    │   岩石层    │
                    └─────────────┘
```

### 检测原理：就像敲西瓜

**Step 1: 用小锤敲击桩顶**

```
        ┌─────────┐
        │  🔨 锤子 │
        └────┬────┘
             │ 敲！
             ▼
        ┌─────────┐
        │  桩顶   │
        └─────────┘
             │
             │ 冲击波向下传播...
```

**Step 2: 波在桩身传播，遇到缺陷会反射**

```
情况A：桩身完好
┌──────────────────────────────┐
│                              │
│      ↓ 入射波                │
│      │                       │
│      │                       │
│      │                       │
│      ▼                       │
│   ┌──┴──┐                    │
│   │桩底 │  ← 波到达桩底      │
│   └──┬──┘                    │
│      │                       │
│      ↑ 桩底反射波            │
│                              │
└──────────────────────────────┘
结果：只有入射波和桩底反射，波形干净

情况B：桩身有缺陷（比如裂缝）
┌──────────────────────────────┐
│                              │
│      ↓ 入射波                │
│      │                       │
│      │                       │
│   ═══╪═══  ← 裂缝！          │
│      ↑                       │
│    缺陷反射波                 │
│      │                       │
│      ↓ 继续传播               │
│      │                       │
│   ┌──┴──┐                    │
│   │桩底 │                    │
│   └──┬──┘                    │
│      ↑                       │
│    桩底反射                   │
│                              │
└──────────────────────────────┘
结果：入射波 → 缺陷反射 → 桩底反射
```

**Step 3: 用传感器接收反射信号**

```
    ┌─────────┐
    │ 🔊 传感器│  ← 接收振动信号
    └────┬────┘
         │
         ▼
    输出电信号给ADC
```

### 你的FPGA就是做这件事

```
│   │   ╱ │ ╲               ╱ │ ╲      ╱ │ ╲                    │
│   │  ╱  │  ╲             ╱  │  ╲    ╱  │  ╲                   │

│   │╱    │    ╲─────────╱    │    ╲╱    │    ╲────────         │
```

### 3.1 VGA 行同步时序（最重要！）

```
一行像素的时间轴（总长800个像素时钟）:

时间轴:     0     96    136   144                        784    792    800
            │     │     │     │                           │      │      │
            │     │     │     │                           │      │      │

hsync信号:
            ┌─────────┐
            │  同步   │
            │  期间   │
            │ (低电平)│
    ─────────┤         ├──────────────────────────────────────────────────
            │   96    │                    704
            │ 个时钟  │
            └─────────┘

            ├─H_SYNC─┤├H_BACK├├H_LEFT├├──────H_VALID (640像素)──────┤├H_FRONT┤
               96       40      8               640                    8

rgb_valid:
                                          ┌─────────────────────────────────┐
    ─────────────────────────────────────┤         有效显示区             ├─────
                                          │           640像素              │
                                          └─────────────────────────────────┘

pix_x:     无效区域                     0 ───────────────────────────► 639
                                          (在有效区内从0开始计数)

说明：
- H_SYNC = 96:   同步脉冲宽度，hsync保持低电平
- H_BACK = 40:   后沿，同步后的等待时间
- H_LEFT = 8:    左边框（overscan区域）
- H_VALID = 640: 实际显示的像素数量
- H_FRONT = 8:   前沿，下一行同步前的等待
- H_TOTAL = 800: 一行总时间
```

### 3.4 I2S 音频数据时序图

```
I2S协议详解：

什么是I2S？
- I2S (Inter-IC Sound) 是一种数字音频传输标准
- 用3根线传输：BCLK(位时钟)、LRCK(左右声道选择)、DATA(数据)
- 就像三个人传球：一个人负责节奏(BCLK)，一个人负责说"左还是右"(LRCK)，一个人负责传数据(DATA)

时序图：

        ┌─────────── 一个LRCK周期 = 64个BCLK ───────────┐
        │                                               │
        │                                               │

BCLK:   ─┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌...┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌
         └┘└┘└┘└┘└┘└┘└┘└┘└┘└┘     └┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘
         │                                                   │
         │← 3.072MHz →                                       │
         │                                                   │

LRCK:   ─────────────────────┐                               ┌──────────────
                              │                               │
         LRCK = 0 (左声道)    │◄───── 32个BCLK ─────►│       │ LRCK = 1 (右)
                              │                       │       │
                              └───────────────────────┘       └──────────────

DATA:   ─────────────────────X─[MSB][B22][B21]...[B0]─X─X────X─[MSB][B22]...
                              │                        │     │
                              │←── 24位左声道数据 ────►│     │←─ 24位右声道
                              │                        │     │
                              ↑                        ↑     ↑
                              │                        │     │
                           LRCK变化后               空闲位  下一声道开始
                           第一个BCLK上升沿                 (MSB有效)
                           采样MSB

关键点：
1. LRCK从0变1（或从1变0）后，第一个BCLK上升沿采样到的是MSB（最高位）
2. 之后每个BCLK上升沿采样一位，从高位到低位
3. 24位数据用24个BCLK，剩下8个是空闲的（64÷2-24=8）
4. 我们用48kHz采样率，每个样本用64个BCLK，所以BCLK = 48kHz × 64 = 3.072MHz

数据是怎么组装的？

移位寄存器工作原理：

    接收前：shift_reg = ??????????????????????????
    
    第1个BCLK上升沿：收到MSB(最高位)
    shift_reg = [MSB]???????????????????????????
                ↑
    
    第2个BCLK上升沿：收到第2位
    shift_reg = [MSB][B22]??????????????????????
                      ↑
    
    第3个BCLK上升沿：收到第3位
    shift_reg = [MSB][B22][B21]????????????????
                            ↑
    
    ...以此类推...
    
    第24个BCLK上升沿：收到LSB(最低位)
    shift_reg = [MSB][B22][B21]...[B1][B0]
                                      ↑
    
    24位全部收完，shift_reg就是完整的音频样本！
```

### 3.5 FIFO 跨时钟域工作原理

```
问题：为什么要用FIFO？

ADC那边：用BCLK (3.072MHz) 时钟，每秒产生48000个样本
VGA这边：用vga_clk (25.175MHz) 时钟，显示刷新率60Hz

两个时钟完全不同步！如果直接连：

    ADC ────────► VGA
    (BCLK域)      (VGA_CLK域)
    
    问题：
    - VGA想读数据时，ADC可能正在写
    - 数据可能丢失或错乱
    - 就像两个人抢话，听不清

解决方法：用FIFO当缓冲区

    ADC ──► 写入FIFO ──► 从FIFO读出 ──► VGA
    (BCLK)   (BCLK写)     (VGA_CLK读)   (VGA_CLK)

FIFO就像一个水箱：

                        ┌─────────────────────────────┐
                        │         FIFO水箱            │
                        │                             │
    ADC (BCLK域)        │  ┌───┬───┬───┬───┬───┐    │     VGA (VGA_CLK域)
    ═════════════       │  │ 1 │ 2 │ 3 │ 4 │...│    │     ═════════════
                       ─┼─►└───┴───┴───┴───┴───┴───┐├─►─
    写水龙头            │        水位               │      读水龙头
    (快，48kHz)         │                          │      (慢，~33kHz)
                        │  写指针w          读指针r │
                        │     ▼               ▼     │
                        └─────────────────────────────┘

    写指针：跟着BCLK走，ADC给一个数据就写一个，指针+1
    读指针：跟着VGA_CLK走，VGA需要数据就读一个，指针+1

FIFO的状态信号：

    ┌─────────────────────────────────────────────────────────────┐
    │                                                             │
    │   fifo_empty (空标志)：读端用                                │
    │       = 1 表示FIFO里没数据了，不能读                         │
    │       = 0 表示有数据，可以读                                 │
    │                                                             │
    │   fifo_full (满标志)：写端用                                 │
    │       = 1 表示FIFO满了，不能写                               │
    │       = 0 表示没满，可以写                                   │
    │                                                             │
    │   fifo_level (水位)：当前有多少个数据                        │
    │       [9:0] 共10位，最大1023                                 │
    │       用于LED指示                                            │
    │                                                             │
    └─────────────────────────────────────────────────────────────┘

在这个项目中的用法：

    写端（ADC侧）：
    ┌────────────────────────────────────────────┐
    │  wrclk  = adc_bclk (3.072MHz)              │
    │  wrreq  = adc_l_valid (左声道数据有效)     │
    │  data   = adc_l_data (左声道24位数据)      │
    │                                            │
    │  每48kHz写一次，每次写24位                  │
    └────────────────────────────────────────────┘
    
    读端（VGA侧）：
    ┌────────────────────────────────────────────┐
    │  rdclk  = vga_clk (25.175MHz)              │
    │  rdreq  = !fifo_empty (有数据就读)         │
    │  q      = 读出的24位数据                   │
    │                                            │
    │  FIFO不空就持续读，读出数据送入波形缓冲    │
    └────────────────────────────────────────────┘
```

### 3.6 波形显示渲染过程

```
波形是怎么画出来的？

核心思想：逐像素判断

显示器每帧扫描一遍所有像素：
    对于每个像素(pix_x, pix_y)：
        判断这个像素应该是什么颜色？
        输出对应的RGB值

波形缓冲区：
    
    wave_buffer[0..511]  ← 存储512个ADC样本
    │
    │   存储的是8位数据（取ADC的高8位）
    │   范围：0~255，中值是128
    │
    └── 写入时机：FIFO读出数据时写入

显示区域定义：

    参数：
        X_LEFT  = 70    波形左边界
        X_RIGHT = 630   波形右边界（共560像素宽）
        Y_TOP   = 60    波形上边界
        Y_BTM   = 420   波形下边界（共360像素高）
        Y_MID   = 240   基线位置（Y坐标中值）

    屏幕坐标：
    
    (0,0) ───────────────────────────────────────────────► (639,0)
      │
      │  Y=5~45: 结果栏区域
      │
      │  Y=60: 波形开始
      │         X=70
      │           │
      │           │   ┌──┐
      │           │   │  │
      │           │───┘  └───  波形
      │           │   Y_MID=240 (基线)
      │           │
      │  Y=420: 波形结束
      │
      ▼
    (0,479)

波形绘制算法：

    对于波形区内的每个像素(pix_x, pix_y)：

    Step 1: 计算这个像素对应波形缓冲区的哪个位置
    
        x_in = pix_x - X_LEFT           (屏幕坐标 → 波形坐标)
        addr = (rd_ptr + x_in) % 512    (加上读指针偏移，循环读取)
        
    Step 2: 从缓冲区取出对应的ADC值
    
        val = wave_buffer[addr]         (取值范围：0~255)
        
    Step 3: 计算这个值对应的屏幕Y坐标
    
        wy = Y_MID + (128 - val)        (中值128对应基线Y_MID)
        
        举例：
            val = 128 (中值)  → wy = 240 + 0 = 240 (正好在基线上)
            val = 200 (较大)  → wy = 240 + (128-200) = 168 (在基线上方)
            val = 56  (较小)  → wy = 240 + (128-56)  = 312 (在基线下方)
            
    Step 4: 判断当前像素是否在波形线上
    
        if (pix_y >= wy-1 && pix_y <= wy+1)
            这个像素在波形线上！画绿色 (RGB = 0x0F0)
        else
            这个像素不在波形线上，画背景色

波形示例：

    假设wave_buffer里存了一个正弦波：

    buffer索引:   0    50   100  150  200  250  300  350  400  450  500
    buffer值:    128  160  190  210  220  210  190  160  128  100   70
    
    画出来的波形：
    
    Y坐标  │
    (屏幕) │
           │      ┌──┐
    180    │     ╱    ╲
           │    ╱      ╲
    200    │   ╱        ╲
           │  ╱          ╲
    220    │ ╱            ╲
           │╱              ╲
    240 ───┼────────────────┼──────── X轴(基线)
           │                 ╲
    260    │                  ╲
           │                   ╲
    280    │                    └──┐
           │
           └──────────────────────────────────────► X坐标
              70                            630
              (X_LEFT)                     (X_RIGHT)
```

### 4.1 PLL时钟生成模块

```verilog
// 文件: rtl/vga_oscilloscope_top.v (第51-58行)

clk_gen u_clk_gen (
    .areset (~sys_rst_n),
    .inclk0 (sys_clk),      // 输入: 50MHz
    .c0     (vga_clk),      // 输出: 25.175MHz (VGA像素时钟)
    .c1     (adc_mclk),     // 输出: 12.288MHz (ADC主时钟)
    .c2     (adc_bclk),     // 输出: 3.072MHz  (I2S位时钟)
    .locked (pll_locked)    // 输出: 锁定标志
);
```

**PLL是什么？**

```
PLL (Phase Locked Loop，锁相环) 是一个时钟倍频/分频器

就像一个"时钟工厂"：

    输入原料: 50MHz 晶振时钟
    │
    ▼
┌─────────────────────────────────────┐
│           PLL (锁相环)              │
│                                     │
│   生产线1: 乘以1007，除以2000       │
│            → 输出 25.175MHz         │
│                                     │
│   生产线2: 乘以768，除以3125        │
│            → 输出 12.288MHz         │
│                                     │
│   生产线3: 对12.288MHz进行4分频     │
│            → 输出 3.072MHz          │
│                                     │
└─────────────────────────────────────┘
    │        │        │
    ▼        ▼        ▼
  c0       c1       c2

为什么需要这些频率？

c0 = 25.175MHz (VGA像素时钟)
    这是VGA 640×480 @ 60Hz 的标准频率
    计算: 800像素/行 × 525行/帧 × 60帧/秒 = 25,200,000 Hz ≈ 25.175MHz
    
c1 = 12.288MHz (ADC主时钟)
    这是音频ADC的标准主时钟
    用于ADC内部的工作时钟
    12.288MHz ÷ 256 = 48kHz (标准音频采样率)
    
c2 = 3.072MHz (I2S位时钟)
    用于I2S数据传输的位时钟
    3.072MHz ÷ 64 = 48kHz (每64个BCK传一个样本)
```

### 4.2 LRCK生成模块

```verilog
// 文件: rtl/vga_oscilloscope_top.v (第75-92行)

// 对BCK进行分频，产生48kHz的LRCK
reg [5:0] lrclk_div;    // 6位计数器，能数到63
reg lrclk_reg;

always @(posedge adc_bclk or negedge vga_rst_n) begin
    if (!vga_rst_n) begin
        lrclk_div <= 6'd0;
        lrclk_reg <= 1'b0;
    end
    else if (lrclk_div == 6'd31) begin  // 数到31翻转
        lrclk_div <= 6'd0;
        lrclk_reg <= ~lrclk_reg;        // 翻转输出
    end
    else begin
        lrclk_div <= lrclk_div + 1'b1;
    end
end

assign adc_lrclk = lrclk_reg;
```

**分频原理图解：**

```
输入: BCLK = 3.072MHz

计数过程:
lrclk_div:  0 → 1 → 2 → ... → 31 → 0 → 1 → ... → 31 → 0 → ...
                               │               │
                               ▼               ▼
lrclk_reg:  ─────────────────┐               ┌────────────────┐
                            │               │                │
                            │   高32个BCK   │   高32个BCK    │
                            └───────────────┘                └──
                            
                            │◄── 低32个BCK ──►│◄── 低32个BCK ──►│

LRCK输出: 48kHz方波

    频率计算:
    一个LRCK周期 = 32个BCK高 + 32个BCK低 = 64个BCK
    LRCK频率 = 3.072MHz ÷ 64 = 48kHz ✓

时序图:

BCLK:    ─┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌
          └┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘└┘
          │                                                     │
          │←──────────────── 64个BCK ────────────────────►│
          
LRCK:    ────────────────────┐                               ┌──
                            │                               │
         (lrclk_div=0~31)   │  (lrclk_div=0~31)             │
         低电平 = 左声道     │  高电平 = 右声道              │
                            └───────────────────────────────┘
```

### 4.3 I2S接收模块

```verilog
// 文件: rtl/iis_slave_rx.v

module iis_slave_rx #(
    parameter DATA_WIDTH  = 24,
    parameter BCLK_DIV    = 32
) (
    input  wire                     rst_n,
    input  wire                     bclk,      // 位时钟
    input  wire                     lrclk,     // 左右声道选择
    input  wire                     sdin,      // 串行数据输入
    output reg  [DATA_WIDTH-1:0]    l_data,    // 左声道并行数据输出
    output reg  [DATA_WIDTH-1:0]    r_data,    // 右声道并行数据输出
    output reg                      l_valid,   // 左声道数据有效脉冲
    output reg                      r_valid    // 右声道数据有效脉冲
);
```

**工作原理：**

```
状态机：

    ┌─────────────────────────────────────────────────────────┐
    │                                                         │
    │   等待LRCLK边沿                                         │
    │         │                                               │
    │         ▼                                               │
    │   ┌──────────────┐                                      │
    │   │  检测到边沿  │                                      │
    │   │  判断是上升沿│                                      │
    │   │  还是下降沿  │                                      │
    │   └──────┬───────┘                                      │
    │          │                                              │
    │          ▼                                              │
    │   ┌──────────────┐      bit_cnt < 24      ┌──────────┐ │
    │   │  开始接收    │──────────────────────►│  移位接收│ │
    │   │  MSB第一位   │                       │  下一位  │ │
    │   └──────────────┘                       └────┬─────┘ │
    │          ▲                                    │       │
    │          │         bit_cnt = 24              │       │
    │          │    ┌──────────────────────────────┘       │
    │          │    │                                      │
    │          │    ▼                                      │
    │   ┌──────────────┐                                   │
    │   │  24位接收完  │                                   │
    │   │  输出有效脉冲│                                   │
    │   │  l_valid/r_valid = 1                            │
    │   └──────────────┘                                   │
    │                                                        │
    └─────────────────────────────────────────────────────────┘

移位过程：

    初始状态:
    shift_reg = [ ? ][ ? ][ ? ][ ? ]...[ ? ][ ? ][ ? ]  (24位，全是未知)
    
    第1个BCK上升沿后 (bit_cnt=0):
    shift_reg = [D23][ ? ][ ? ][ ? ]...[ ? ][ ? ][ ? ]  (D23是MSB)
                 ↑
               采样sdin
    
    第2个BCK上升沿后 (bit_cnt=1):
    shift_reg = [D23][D22][ ? ][ ? ]...[ ? ][ ? ][ ? ]
                      ↑
    
    第3个BCK上升沿后 (bit_cnt=2):
    shift_reg = [D23][D22][D21][ ? ]...[ ? ][ ? ][ ? ]
                           ↑
    
    ... 继续采样 ...
    
    第24个BCK上升沿后 (bit_cnt=23):
    shift_reg = [D23][D22][D21][D20]...[D2][D1][D0]  (全部接收完毕)
                                            ↑
                                          D0是LSB
                                          
    此时:
    - 如果刚才接收的是左声道，则 l_data = shift_reg, l_valid = 1
    - 如果刚才接收的是右声道，则 r_data = shift_reg, r_valid = 1
```

### 4.4 VGA时序控制模块

```verilog
// 文件: rtl/vga_ctrl_simple.v

module vga_ctrl_simple (
    input  wire         vga_clk,
    input  wire         sys_rst_n,
    output wire [9:0]   pix_x,      // 当前像素X坐标 (0~639)
    output wire [9:0]   pix_y,      // 当前像素Y坐标 (0~479)
    output wire         rgb_valid,  // 是否在有效显示区
    output wire         hsync,      // 行同步信号
    output wire         vsync       // 场同步信号
);

// 时序参数
parameter H_SYNC    = 10'd96,   // 行同步脉冲宽度
          H_BACK    = 10'd40,   // 行后沿
          H_LEFT    = 10'd8,    // 行左边框
          H_VALID   = 10'd640,  // 行有效显示
          H_RIGHT   = 10'd8,    // 行右边框
          H_FRONT   = 10'd8,    // 行前沿
          H_TOTAL   = 10'd800;  // 行总周期

parameter V_SYNC    = 10'd2,    // 场同步脉冲宽度
          V_BACK    = 10'd25,   // 场后沿
          V_TOP     = 10'd8,    // 场上边框
          V_VALID   = 10'd480,  // 场有效显示
          V_BOTTOM  = 10'd8,    // 场下边框
          V_FRONT   = 10'd2,    // 场前沿
          V_TOTAL   = 10'd525;  // 场总周期
```

**计数器工作原理：**

```
行计数器 cnt_h:

    每个vga_clk上升沿，cnt_h加1
    当cnt_h达到799(H_TOTAL-1)时，归零
    
    cnt_h:  0 → 1 → 2 → ... → 799 → 0 → 1 → ...
    
    根据cnt_h的值判断当前处于哪一阶段：
    
    cnt_h范围          阶段              hsync    rgb_valid
    ─────────────────────────────────────────────────────────
    0~95 (共96)        同步期            0        0
    96~135 (共40)      后沿              1        0
    136~143 (共8)      左边框            1        0
    144~783 (共640)    有效显示          1        1
    784~791 (共8)      右边框            1        0
    792~799 (共8)      前沿              1        0

场计数器 cnt_v:

    每当cnt_h归零时（一行结束），cnt_v加1
    当cnt_v达到524(V_TOTAL-1)且cnt_h也归零时，cnt_v归零
    
    cnt_v范围          阶段              vsync    rgb_valid
    ─────────────────────────────────────────────────────────
    0~1 (共2)          同步期            0        0
    2~26 (共25)        后沿              1        0
    27~34 (共8)        上边框            1        0
    35~514 (共480)     有效显示          1        1
    515~522 (共8)      下边框            1        0
    523~524 (共2)      前沿              1        0

像素坐标计算：

    pix_x = cnt_h - (H_SYNC + H_BACK + H_LEFT)
          = cnt_h - 144
    
    当cnt_h在有效区(144~783)时：
        pix_x = 0~639
    
    pix_y = cnt_v - (V_SYNC + V_BACK + V_TOP)
          = cnt_v - 35
    
    当cnt_v在有效区(35~514)时：
        pix_y = 0~479
```

### 4.5 波形显示模块

```verilog
// 文件: rtl/vga_waveform.v

module vga_waveform (
    input  wire         vga_clk,
    input  wire         rst_n,
    input  wire [23:0]  ad_data,       // ADC数据输入 (24位)
    input  wire         ad_data_vld,   // 数据有效标志
    input  wire [9:0]   pix_x,         // 当前像素X坐标
    input  wire [9:0]   pix_y,         // 当前像素Y坐标
    input  wire         rgb_valid,     // 是否在有效显示区
    input  wire [7:0]   trigger_level, // 触发电平
    input  wire         pause_en,      // 暂停使能
    output reg  [11:0]  rgb            // 颜色输出 (R4G4B4)
);
```

**波形缓冲区：**

```verilog
// 512个字节的存储器，存储ADC数据
(* ramstyle = "M9K" *) reg [7:0] wave_buffer [0:511];

// 写入逻辑
always @(posedge vga_clk or negedge rst_n) begin
    if (!rst_n) begin
        wr_ptr <= 9'd0;
    end
    else if (ad_data_vld) begin
        wave_buffer[wr_ptr] <= ad_data[23:16] ^ 8'h80;  // 取高8位并翻转符号
        wr_ptr <= wr_ptr + 1'b1;
    end
end
```

**为什么取高8位并翻转符号？**

```
ADC数据格式：
    ad_data[23:0] 是24位有符号数
    
    范围: -8388608 ~ +8388607
    中心值: 0 (对应无信号)

我们想要的无符号格式：
    范围: 0 ~ 255
    中心值: 128 (对应无信号)

转换过程：
    1. 取高8位: ad_data[23:16]
       范围变成: 0~255 (但128对应原来的0)
    
    2. 翻转符号位: ^ 8'h80
       - 如果ad_data[23:16] = 0x80 (128), 结果 = 0
       - 如果ad_data[23:16] = 0xFF (255), 结果 = 0x7F (127)
       - 如果ad_data[23:16] = 0x00 (0),   结果 = 0x80 (128)
       
    等等，这里的翻转符号位其实是把有符号转无符号的简便方法：
    - 正数(>0) → 转换后 < 128
    - 负数(<0) → 转换后 > 128
    - 0       → 转换后 = 128
```

**RGB输出逻辑：**

```verilog
always @(posedge vga_clk or negedge rst_n) begin
    if (!rst_n)
        rgb <= 12'b0;
    else if (rgb_valid) begin
        // 波形（最高优先级）
        if (on_wave)
            rgb <= 12'h0F0;       // 绿色波形
            
        // 标注
        else if (on_incident_mark)
            rgb <= 12'h0F0;       // 绿色入射波标注
        else if (on_defect_up)
            rgb <= 12'hFF0;       // 黄色缩径标注
        else if (on_defect_down)
            rgb <= 12'h0FF;       // 青色扩径标注
        else if (on_bottom_mark)
            rgb <= 12'hF0F;       // 紫色桩底标注
        else if (on_trig_mark)
            rgb <= 12'hF00;       // 红色触发点
            
        // 结果栏信息（白色）
        else if (on_result_bar || on_result_text)
            rgb <= 12'hFFF;
            
        // 坐标轴（白色）
        else if (on_y_axis || on_x_axis)
            rgb <= 12'hFFF;
        else if (on_y_tick || on_x_tick)
            rgb <= 12'h888;       // 灰色刻度
        else if (on_trig_line)
            rgb <= 12'hF00;       // 红色触发电平线
            
        else
            rgb <= 12'b000;       // 黑色背景
    end
    else
        rgb <= 12'b0;
end
```

