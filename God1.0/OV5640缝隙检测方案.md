# OV5640 缝隙检测系统设计方案

> 基于 Altera Cyclone IV E (EP4CE6E22C8) FPGA + 野火 OV5640 摄像头
> 测量 A4 纸上两个黑色矩形之间的缝隙宽度
> 创建日期: 2026-07-26

---

## 一、项目背景

### 任务需求

- 使用野火 OV5640 摄像头俯视拍摄 A4 纸
- 检测纸上两个黑色矩形之间的缝隙宽度
- 输出测量结果(像素数 + 物理尺寸 mm)
- 通过按键切换工作模式(波形显示 / 摄像头测量)

### 硬件平台

| 部件 | 规格 |
|------|------|
| FPGA | Altera Cyclone IV E, EP4CE6E22C8 (TQFP144) |
| 摄像头 | 野火 OV5640 (直连型,无 AL422B FIFO) |
| 显示 | VGA 800×600 @ 60Hz (40MHz 像素时钟) |
| 串口 | 2 Mbps波特率 |
| 数码管 | 74HC595 驱动 (复用现有 seg_display 模块) |

### 现有资源情况 (2026-07-26 编译实测)

| 资源 | 总量 | 已用 | 剩余 | 占比 |
|------|------|------|------|------|
| LE | 6,272 | 1,414 | 4,858 | 23% |
| 存储 bit (M9K) | 276,480 | 22,528 | 253,952 | 8% |
| 9-bit 乘法器 | 30 | 10 | 20 | 33% |
| PLL | 2 | 1 | 1 | 50% |
| 引脚 | 92 | 24 | 68 | 26% |

## 二、关键技术决策

### 2.1 为什么不用 VGA 实时显示摄像头图像

**根本原因: 帧率不匹配,且无外挂 SDRAM 做帧缓存**

| 端 | 帧率 | 像素率 |
|----|------|--------|
| OV5640 (SVGA 800×600) | 30 fps | ~24-28 MHz |
| VGA 800×600@60Hz | 60 fps (固定) | 40 MHz |

- 摄像头写: 30fps × 800×600×2 = 28.8 MB/s
- VGA 读: 60fps × 800×600×2 = 57.6 MB/s (读得比写快一倍)
- 帧缓存需求: 800×600×16bit = 7.68 Mbit (远超 EP4CE6 的 276 Kbit M9K)
- EP4CE6E22C8 板子无外挂 SDRAM/DDR3

**结论**: EP4CE6 这块板子做不了干净的 OV5640 实时 VGA 显示,只能采用其他调试方式。

### 2.2 调试方案选择: UART 传降采样图 + Qt 上位机

**为什么选这个方案**:

- 2 Mbps 波特率 = 200,000 字节/秒 (8N1 格式)
- 80×60 灰度图 = 4800 字节/帧,可达 ~41 fps
- 资源占用极小 (~670 LE)
- 调试体验好: PC 端实时看预览 + 检测行 Y 曲线
- 不依赖外挂 RAM,完全在 EP4CE6 内实现

### 2.3 Qt 选型: QWidget + C++ (非 QML)

| 对比项 | QML | C++ QWidget (选用) |
|--------|-----|-------------------|
| 实时图像刷新(40fps) | Scene Graph 异步,有延迟 | QPainter 直接绘制 |
| 自定义画 Y 曲线 | Canvas 性能差 | paintEvent 直接画 |
| 缝隙标线叠加 | 需要叠层 | QPainter 直接在 QImage 上画 |
| 串口数据处理 | 要 C++ 后端 + QML 前端 | 全 C++,数据流直接 |
| 适用场景 | 现代/动画 UI | 工业测量/数据可视化 |

**选用 QWidget + C++**,工业测量界面的正解。

### 2.4 集成方式: 按键切换模式

- 复用现有 `mode_btn` 按键切换工作模式
- 模式 0: 波形显示 (现有功能,不可变基准)
- 模式 1: 摄像头缝隙检测 (新增功能)
- 需要修改 `vga_dual_mode_top.v` (碰基准边缘,但只动模式切换分支)
- VGA 时序/按键消抖/示波器路径/RGB 选择等核心逻辑不动

### 2.5 通信方式: 双向 UART

- FPGA → PC: 图像 + 测量结果 (2 Mbps)
- PC → FPGA: 阈值/标定系数/检测行选择指令 (也用 2 Mbps)

## 三、系统架构

### 3.1 整体框图

```
                        PCLK 域 (~24MHz)
OV5640 ──────────────────┬──> gap_detect ──> gap_vote ──┐
  │                       │                              │ [同步器]
  D[7:0]/PCLK/HREF/VSYNC  └──> Y提取 ──> 降采样 80×60    │
                                                          ▼
                              UART_TX (2Mbps) <── 帧打包 ─┴── gap_mm
                                  │
                                  ▼
                           USB转串口
                                  │
                                  ▼
                       Qt 6.2.4 上位机 (QWidget + C++)
                       ├─ 预览图(80×60放大到480×360)
                       ├─ 检测行Y曲线
                       ├─ 缝隙标线
                       └─ mm值显示 + 阈值调节

           PC → FPGA 指令 (双向)
           UART_RX <── 阈值/标定/行选择指令
```

### 3.2 时钟域架构

| 时钟域 | 频率 | 来源 | 用途 |
|--------|------|------|------|
| sys_clk | 50MHz | 板载晶振 | 系统主时钟 |
| vga_clk | 40MHz | PLL c0 | VGA 800×600 像素时钟 |
| bclk | 6.144MHz | PLL c2 | I2S 位时钟 (现有,保留) |
| **xclk** | **24MHz** | **PLL c1 (新启用)** | **OV5640 主时钟** |
| pclk | ~24MHz | OV5640 输出 | 摄像头像素时钟 |
| uart_clk | 50MHz | sys_clk | UART 波特发生 (50M / 2M = 25 分频) |

> 复用现有 PLL,c1 输出 24MHz 给 OV5640,不新增 PLL。

### 3.3 跨时钟域处理

| 信号类型 | 处理方式 |
|----------|----------|
| PCLK → VGA_CLK (测量结果) | 握手协议 (gap_pix 是 16-bit) |
| PCLK → UART_CLK (图像数据) | 同时钟域 (UART 用 PCLK 或同源时钟) |
| UART_CLK → PCLK (控制指令) | 握手协议 + 2级同步器 |
| 按键输入 (现有) | 不变,沿用现有消抖 |

## 四、FPGA 端模块设计

### 4.1 模块清单

| 模块 | 功能 | LE | M9K | 备注 |
|------|------|----|-----|------|
| `ov5640_config.v` | SCCB 配置 OV5640 寄存器 | ~80 | 0 | 状态机驱动 SCCB |
| `ov5640_capture.v` | 帧同步 + 行同步 + Y 通道提取 | ~150 | 0 | YUV422 取 Y 字节 |
| `gap_detect.v` | 单行扫描状态机,输出 gap_pix | ~250 | 0 | 4状态 FSM |
| `gap_vote.v` | 多行中位数投票,稳定输出 | ~80 | 1 | 中间区域 200 行投票 |
| `downsample.v` | 流式降采样 800×600 → 80×60 | ~80 | 0 | 每10像素取1,每10行取1 |
| `uart_tx_2M.v` | 2Mbps UART 发送器 + 帧打包 | ~110 | 1 | 含发送 FIFO |
| `uart_rx_2M.v` | 2Mbps UART 接收器 (PC指令) | ~80 | 0 | 解析控制指令 |
| `gap_calibrate.v` | 像素→毫米换算 | ~50 | 0 | 用 DSP 乘法器 |
| **合计** | | **~880** | **2** | 占剩余资源 ~15% |

### 4.2 模块接口

#### ov5640_config.v (SCCB 配置)

```verilog
module ov5640_config (
    input  wire        clk,          // 50MHz 系统时钟
    input  wire        rst_n,
    output wire        sclk,         // SCCB 时钟 (~400kHz)
    inout  wire        sdat,         // SCCB 数据 (OD)
    output wire        config_done   // 配置完成标志
);
// 内部 ROM 存储寄存器配置表 (分辨率/格式/曝光等)
```

#### ov5640_capture.v (图像采集 + Y 提取)

```verilog
module ov5640_capture (
    input  wire        pclk,         // OV5640 像素时钟
    input  wire        rst_n,
    // OV5640 接口
    input  wire [7:0]  cam_data,
    input  wire        cam_href,
    input  wire        cam_vsync,
    // 输出
    output wire [7:0]  y_data,       // Y 通道 (亮度)
    output wire        y_valid,
    output wire [9:0]  pix_x,        // 列坐标 0-799
    output wire [9:0]  pix_y,        // 行坐标 0-599
    output wire        frame_sync    // 帧起始脉冲
);
// YUV422 交替: Y U Y V Y U Y V ... 取偶数位置的 Y
```

#### gap_detect.v (行扫描缝隙检测)

```verilog
module gap_detect (
    input  wire        pclk,
    input  wire        rst_n,
    input  wire [7:0]  y_data,
    input  wire        y_valid,
    input  wire [9:0]  pix_x,
    input  wire [9:0]  pix_y,
    input  wire [7:0]  threshold,    // 二值化阈值 (PC可调)
    input  wire [9:0]  detect_row,   // 检测行 (PC可调, 默认300)
    // 输出
    output reg  [9:0]  gap_pix,      // 缝隙像素宽度
    output reg         gap_valid,    // 检测有效脉冲
    output reg  [6:0]  gap_left,     // 缝隙左边界 (80-wide 坐标 0-79)
    output reg  [6:0]  gap_right     // 缝隙右边界 (80-wide 坐标 0-79)
);
// 状态机: IDLE → WAIT_BLK1 → IN_RECT1 → IN_GAP → IN_RECT2 → DONE
// gap_left/gap_right 在 IN_RECT1→IN_GAP 与 IN_GAP→IN_RECT2 跳转时锁存
// 当 gap_valid=0 时, gap_left/gap_right 输出 0x7F (79) 作哨兵, uart_tx 会转 0xFF
```

> 注: gap_left/gap_right 在 v1 方案中是 10-bit (pix_x 全分辨率), 在 v2 中改为 7-bit (80-wide)
> 因为只有降采样后的图像才传到 PC, 80-wide 已够画线精度。FPGA 内部仍可用全分辨率计算。

#### gap_vote.v (多行中位数)

```verilog
module gap_vote #(
    parameter VOTE_LINES = 64  // 投票行数
) (
    input  wire        pclk,
    input  wire        rst_n,
    input  wire [9:0]  gap_pix,
    input  wire        gap_valid,
    // 输出
    output reg  [9:0]  gap_pix_stable,  // 稳定的像素宽度
    output reg         stable_valid     // 接 uart_tx status bit1
);
// 收集 VOTE_LINES 个有效值,排序取中位数
// 简化版: 取众数 (实现更省资源)
// stable_valid 拉高条件: 至少收到 N 个有效样本且众数占比 > 60%
```

#### gap_calibrate.v (像素→毫米换算)

```verilog
module gap_calibrate (
    input  wire        clk,
    input  wire        rst_n,
    input  wire [9:0]  gap_pix,        // 像素宽度
    input  wire        valid,
    input  wire [15:0] calib_coef,     // 标定系数 (K × 10000, Q12.4 定点)
    // 输出
    output reg  [15:0] gap_mm_x10,     // 毫米值 × 10 (用于显示)
    output reg         mm_valid
);
// gap_mm_x10 = gap_pix × calib_coef / 1000
// 用 1 个 DSP 乘法器
```

#### downsample.v (流式降采样)

```verilog
module downsample (
    input  wire        pclk,
    input  wire        rst_n,
    input  wire [7:0]  y_data,
    input  wire        y_valid,
    input  wire [9:0]  pix_x,
    input  wire [9:0]  pix_y,
    // 输出 (80×60 = 4800 像素)
    output reg  [7:0]  ds_y_data,
    output reg         ds_y_valid,
    output reg  [6:0]  ds_pix_x,   // 0-79
    output reg  [5:0]  ds_pix_y    // 0-59
);
// pix_x % 10 == 0 且 pix_y % 10 == 0 时输出
```

#### uart_tx_2M.v (2Mbps 发送器 + 帧打包)

```verilog
module uart_tx_2M (
    input  wire        clk,          // 50MHz
    input  wire        rst_n,
    // 数据输入 (来自降采样器)
    input  wire [7:0]  tx_data,
    input  wire        tx_valid,
    output wire        tx_ready,
    // 测量结果 (来自 gap_detect + gap_vote + gap_calibrate)
    input  wire [15:0] gap_pix,         // 来自 gap_vote (稳定后)
    input  wire        gap_valid,       // 来自 gap_detect (单帧)
    input  wire        stable_valid,    // 来自 gap_vote
    input  wire [15:0] gap_mm_x10,      // 来自 gap_calibrate
    input  wire [9:0]  detect_row,      // 来自 CMD_SET_ROW 寄存器
    input  wire [6:0]  gap_left,        // 来自 gap_detect (80-wide)
    input  wire [6:0]  gap_right,       // 来自 gap_detect (80-wide)
    // 串口输出
    output reg         txd
);
// 波特率: 50MHz / 2Mbps = 25 分频
// 8N1 格式
// 内置 256 字节 FIFO 缓冲
//
// 帧组装 (v2 协议):
//   byte5 status = {3'b000, 1'b1(v2), row[9:8], stable_valid, gap_valid}
//   byte6 gap_left  = gap_valid ? gap_left  : 8'hFF
//   byte7 gap_right = gap_valid ? gap_right : 8'hFF
//   v2 bit 恒为 1, 上位机据此采信 gap_left/right
```

#### uart_rx_2M.v (2Mbps 接收器,PC指令)

```verilog
module uart_rx_2M (
    input  wire        clk,          // 50MHz
    input  wire        rst_n,
    input  wire        rxd,
    // 输出解析后的指令
    output reg  [7:0]  cmd,
    output reg  [15:0] cmd_data,
    output reg         cmd_valid
);
// 协议: 0x5A <cmd> <data_hi> <data_lo> <checksum>
// cmd: 0x01=设阈值, 0x02=设标定系数, 0x03=选检测行
```

## 五、通信协议

### 5.1 FPGA → PC (图像 + 结果, 2 Mbps)

```
帧格式 (v2 协议):
┌──────────┬─────────────────────┬───────────────────────────────────────┬──────────┐
│ 帧头 4B  │ 图像数据 4800B       │ 测量结果 8B                            │ 帧尾 4B  │
├──────────┼─────────────────────┼───────────────────────────────────────┼──────────┤
│ AA 55    │ 80×60 Y 值          │ byte 0: gap_pix_hi                    │ 55 AA    │
│ AA 55    │ (逐行扫描)          │ byte 1: gap_pix_lo                    │ 55 AA    │
│          │                     │ byte 2: gap_mm_x10_hi                 │          │
│          │                     │ byte 3: gap_mm_x10_lo                 │          │
│          │                     │ byte 4: detect_row_lo (低 8 位)       │          │
│          │                     │ byte 5: status                        │          │
│          │                     │ byte 6: gap_left (80-wide, 0xFF=N/A)  │          │
│          │                     │ byte 7: gap_right (80-wide, 0xFF=N/A) │          │
└──────────┴─────────────────────┴───────────────────────────────────────┴──────────┘

总长: 4 + 4800 + 8 + 4 = 4816 字节/帧
帧率: 200000 / 4816 ≈ 41 fps
```

#### status 字节位定义 (v2)

| Bit | 名称 | 说明 |
|-----|------|------|
| 0 | `valid` | 单帧 `gap_valid` (gap_detect 输出) |
| 1 | `stable` | 投票稳定 `stable_valid` (gap_vote 输出) |
| 2-3 | `row_hi` | detect_row 的高 2 bit (bit 8-9), 与 byte 4 拼成完整 10-bit 行号 0-599 |
| 4 | `v2` | v2 协议标识位 (FPGA 已实现 gap_left/right 传输) |
| 5-7 | reserved | 保留, 必须为 0 |

#### gap_left / gap_right 字段

- 取值范围 0-79 (80-wide 降采样后坐标, 对应 800×600 全图的 0-790)
- `0xFF` 表示本帧未计算 (例如 `gap_valid=false` 时)
- 仅当 `status.v2=1` 时才采信此字段; v1 FPGA 在 byte 6/7 发 0, 上位机应忽略

#### 与 v1 协议的差异

| 字段 | v1 | v2 |
|------|----|----|
| byte 4 | `detect_row` (只发低 8 bit, 实际范围 0-255) | `detect_row_lo` (低 8 bit) |
| byte 5 | `status`, 仅 bit0=valid | `status`, 含 valid/stable/row_hi/v2 四组位 |
| byte 6 | reserved (固定 0) | `gap_left` (0-79 或 0xFF) |
| byte 7 | reserved (固定 0) | `gap_right` (0-79 或 0xFF) |

**向后兼容**: v1 FPGA 在 byte 5 的 bit4 恒为 0 → 上位机识别为 v1 → gap_left/right 不采信, 退回 PC 端重算。

### 5.2 PC → FPGA (控制指令, 2 Mbps)

```
指令格式: 0x5A <cmd> <data_hi> <data_lo> <checksum>

cmd 列表:
  0x01  设阈值        data = 阈值 (0-255)
  0x02  设标定系数    data = K × 10000 (Q12.4 定点, 上限 65535)
  0x03  选检测行      data = 行号 (0-599, 完整 10 bit)
  0x04  开始/停止采集  data = 0x01/0x00

checksum = cmd ^ data_hi ^ data_lo
```

> 标定系数 data 范围受 uint16_t 限制为 0-65535, K 上限 = 6.5535 mm/pix。
> 上位机 `CalibrationDialog` 会在超限时显示警告并 clamp, 不下发截断值。

## 六、核心算法

### 6.1 行扫描状态机 (gap_detect.v)

```
状态转移:
  IDLE      ──(HREF上升沿)──> WAIT_BLK1
  WAIT_BLK1 ──(Y<TH)──> IN_RECT1        (找到第一个黑矩形)
  IN_RECT1  ──(Y>TH)──> IN_GAP          (记录 gap_left = pix_x)
  IN_GAP    ──(Y<TH)──> IN_RECT2        (记录 gap_right = pix_x)
  IN_RECT2  ──(HREF下降沿)──> IDLE      (计算 gap_pix = right - left + 1)

约束:
  - 只在 detect_row 指定的行做检测
  - 若状态机未走到 IN_RECT2,输出 gap_valid=0 (本行无效)
```

### 6.2 多行中位数投票 (gap_vote.v)

```
1. 选取图像中间 1/3 区域 (行 200-400, 共 200 行)
2. 每帧收集所有有效行的 gap_pix 值
3. 取中位数 (或众数,实现更省资源)
4. 输出 gap_pix_stable

简化实现 (省资源版):
  - 用 64 个寄存器存最近 64 个有效值
  - 用冒泡排序取中位数
  - 或用直方图统计取众数 (1 个 M9K 做 1024 桶直方图)
```

### 6.3 像素→毫米换算 (gap_calibrate.v)

```
标定流程:
  1. 打印一张已知缝隙 (如 10.0 mm) 的标准图
  2. 摄像头对准,读取 gap_pix_stable 值 (假设 = 85 pix)
  3. 计算系数 K = 10.0 / 85 = 0.1176 mm/pix
  4. 通过 PC 指令写入 calib_coef = 0.1176 × 10000 = 1176
  5. 实测: gap_mm_x10 = gap_pix × calib_coef / 1000

资源: 1 个 9-bit DSP 乘法器
```

## 十一、风险与应对

| 风险 | 概率 | 应对 |
|------|------|------|
| OV5640 寄存器配置错误,不出图 | 中 | 用野火 STM32 例程的寄存器配置作参考 |

## 十二、注意事项

1. **修改 vga_dual_mode_top.v 前必须先备份**,并在编辑前显式询问用户确认
2. **每次修改 RTL 后必须清理 Quartus 编译缓存**:
   ```powershell
   Remove-Item -Recurse -Force quartus/db, quartus/incremental_db, quartus/output_files/greybox_tmp -ErrorAction SilentlyContinue
   ```
3. **OV5640 引脚不能加 WEAK_PULL_UP_RESISTOR** (Cyclone IV E 部分引脚不支持)
4. **跨时钟域复位**: CDC 同步器必须用目的域的同步后复位
5. **M9K RAM 读写**: 必须各自在独立的 `always @(posedge clk)` 块中,不含异步复位
6. **不要使用 UART 收发器外部 IP**,自己写以避免 IP 依赖

## 附录 B: 标定系数计算示例

```
已知缝隙宽度: W_real = 10.0 mm
FPGA 测得像素宽度: gap_pix = 85

标定系数: K = W_real / gap_pix = 10.0 / 85 = 0.1176 mm/pix

写入 FPGA (Q12.4 定点): calib_coef = K × 10000 = 1176

实测换算:
  gap_mm_x10 = gap_pix × calib_coef / 1000
             = 85 × 1176 / 1000
             = 99.96
             ≈ 100  (即 10.0 mm,× 10 后是 100)
```

### v1.1 (2026-07-26) — 协议层 v2 改动

#### 问题
1. gap_left / gap_right 未在协议中传输

3. status 字段语义不明 (未区分单帧 valid 与稳定 valid)

- byte 4 重命名为 detect_row_lo, 高 2 bit 移到 status bit 2-3
- byte 5 status 扩展: bit0=valid, bit1=stable, bit2-3=row_hi, bit4=v2 标识
- byte 6/7 由 reserved 改为 gap_left / gap_right (0xFF=未计算)
- 标定系数 clamp 到 [0, 65535] 防止 0xFFFF 截断
