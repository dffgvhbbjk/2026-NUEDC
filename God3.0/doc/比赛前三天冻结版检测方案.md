# 比赛前三天冻结版检测方案

## 1. 约束与结论

当前约束：

- 比赛现场不能使用现场棒进行校准；
- 只能使用现有自有棒提前采集模板；
- 现场棒长度可能相对 1m 多或少约 1mm；
- 自有棒本身也不保证恰好 1000mm；
- 剩余时间只有 3 天，不能再引入高风险的大规模算法。

因此最终方案采用：

> 赛前离线采集并固化模板；比赛现场只测量、不学习、不更新模板；
> 每次敲击都进行幅值归一化和时间归一化；判断使用多特征规则，
> 不依赖单个固定峰值或单个绝对阈值。

不建议继续使用“上电后拿正常棒自动校准”的运行方式。比赛现场若不允许
校准，所有参考参数必须在赛前写入 FPGA，运行期间只读。

## 2. 误差来源优先级

### 2.1 棒长相差 ±1mm

对于约 1000mm 棒：

```text
1mm / 1000mm = 0.1%
```

即使缺陷位于 500mm，因棒长 ±1mm 引起的位置误差也只有约 ±0.5mm。
它远小于当前约 10～14mm/采样点的时间量化误差，因此不是主要问题。

### 2.2 自有棒不是标准 1m

必须现在用可靠卷尺或钢尺测量自有棒的实际长度 `L_ref_mm`，至少重复测量
3 次取中值。模板的所有距离标签使用实际长度，不再默认写死 1000mm。

若比赛明确规定现场棒标称长度为 1000mm，则最终毫米输出使用
`L_test_mm = 1000`。自有棒长度只用于建立无量纲模板，不直接替代现场棒
长度。

### 2.3 材料波速和安装差异

这是最大风险。固定使用 83 点会把材料波速差异直接变成距离比例误差。
解决方法不是现场修改 83，而是优先从每次敲击自身的棒底反射获得时间尺度。

定义：

```text
T0   = 主冲击中心
Tend = 本次波形中的棒底反射中心
Tdef = 缺陷反射中心
```

若本次能够找到棒底反射：

```text
位置比例 r = (Tdef - T0) / (Tend - T0)
距离 mm    = r × L_test_mm
```

这样能够抵消大部分材料波速、采样率和固定延迟差异。该过程属于每次测量的
内部计算，不修改模板，因此不是现场校准。

如果断裂导致棒底反射完全消失，只能退化为：

```text
距离 mm = (Tdef - T0) × L_ref_mm / D_ref
```

其中 `D_ref` 是赛前模板的正常棒底间隔。该结果必须标为低置信度；没有任何
算法能在材料波速未知且棒底反射完全不可见时同时保证绝对距离高精度。

## 3. 赛前模板怎么采

### 3.1 固定机械条件

以下条件必须固定并带到比赛：

- 同一个传感器；
- 同一安装位置、方向和固定压力；
- 同一种耦合方式；
- 同一个锤头；
- 敲击端位置使用物理定位标记；
- ADC 增益和供电不变；
- 固定使用 256 点采集；
- PIN_59 平滑状态固定，不允许模板和比赛使用不同设置。

安装一致性比增加复杂算法更重要。

### 3.2 最小数据量

时间紧张时至少采集：

| 数据 | 数量 | 要求 |
|---|---:|---|
| 正常棒，轻敲 | 10 次 | 能稳定触发 |
| 正常棒，中等力度 | 20 次 | 主要模板 |
| 正常棒，较重敲 | 10 次 | 检查幅值鲁棒性 |
| 已知缺陷棒/模拟缝隙 | 每个位置 10 次 | 至少近、中、远三档 |
| 静止噪声 | 30 秒 | 统计误触发 |
| 碰线、碰桌面、脚踩地面 | 各 10 次 | 必须拒绝 |

每次保存 UART 导出的完整 256 点原始波形，并记录：

```text
棒实际长度、缺陷实际位置、敲击力度档、平滑状态、是否有效、人工备注
```

### 3.3 模板预处理

在 PC 上离线完成：

1. 基线扣除；
2. 取绝对值并做 5～8 点包络；
3. 对齐主冲击中心 `T0`；
4. 用主冲击峰值归一化幅值；
5. 正常棒能够找到棒底时，用 `Tend-T0` 归一化时间；
6. 对所有正常棒波形逐点取中位数，得到正常模板；
7. 逐点计算 MAD（中位绝对偏差），得到允许波动带；
8. 模板和阈值转成定点常数后固化进 RTL。

不建议只保存一条“最好看的波形”。中位数模板比单次模板更能抵抗敲击力度
和安装微小变化。

## 4. 现场触发方案

### 4.1 当前无波形的高概率原因

当前 `wave_trigger` 使用：

```text
noise_peak = 1024 点窗口内的最大值
trigger_threshold = max(30000, noise_peak × 4)
```

最大值估计非常容易被碰线、插拔和单点冲击污染。一个异常大点就可能让后续
约一个窗口的阈值过高，造成正常锤击无法触发。

缺陷分析器里的反射阈值不会阻止 VGA 采集；如果完全没有新波形，应先查
采集触发器，而不是继续调整缺陷阈值。

### 4.2 三天内推荐的触发器

不再使用窗口最大值作为噪声代表，改用绝对值的慢速平均：

```text
noise_ema += (magnitude - noise_ema) / 64
threshold = clamp(noise_ema × K, TH_MIN, TH_MAX)
```

初始建议：

```text
K             = 6
TH_MIN        = 20000～30000
TH_MAX        = 根据实测主冲击最小幅值确定
TRIG_CONFIRM  = 2 点
```

保护规则：

- `magnitude > threshold/2` 时暂停更新 `noise_ema`；
- 进入采集后冻结噪声估计；
- 重新武装后先观察一小段静默，再允许触发；
- 阈值上限不得超过“轻敲主冲击峰中位数”的约 1/3；
- 阈值下限必须高于静止噪声高分位值。

最终常数必须由当天真实数据决定，不能继续凭感觉增减。

### 4.3 看 VGA 状态快速定位

```text
一直 WARMUP：ADC/FIFO 没有持续送样，不是阈值问题
停在 ARMED/READY，敲击无变化：触发阈值过高或传感器信号过小
进入 CAPTURE/HOLD 但没曲线：显示/RAM/增益问题
一直 HOLD：重新武装静默条件问题
```

## 5. 检测逻辑

### 5.1 信号有效性门控

先判断本次敲击是否有效：

- 主冲击峰必须高于触发阈值一定倍数；
- 主冲击不得饱和；
- 主冲击宽度必须落在模板范围；
- 触发前噪声不得过大；
- 至少找到一个可靠反射波包。

不满足时输出 `INVALID/RETRY`，绝不能输出 `NORMAL`。

### 5.2 主冲击与尾振隔离

1. 在触发后窗口内找主冲击峰/中心；
2. 包络连续低于反射阈值 6 点后，才允许搜索反射；
3. 搜索开始后保存所有可靠反射包，而不是只保存第一个超过阈值的点；
4. 每个反射包记录：

```text
峰位置、峰幅值、能量、宽度、相对主冲击幅值
```

单点尖峰和过窄波包直接丢弃。

### 5.3 棒底候选

在模板参考间隔 `D_ref` 的宽窗口中搜索棒底：

```text
0.65 × D_ref ～ 1.35 × D_ref
```

候选评分使用：

- 与正常模板棒底波包的时间接近程度；
- 波包宽度；
- 波包能量；
- 极性/包络形状；
- 是否存在连续有效点。

不要简单地把“最后一个峰”当棒底。

### 5.4 缺陷候选

缺陷候选应同时满足：

- 位于主冲击尾振结束之后；
- 位于棒底候选之前；
- 连续 3 点以上；
- 峰值或能量高于噪声门限；
- 相对主冲击幅值超过赛前数据确定的下限；
- 相对正常模板的局部偏差超过 `median + K×MAD`。

建议输出第一个高置信度缺陷，而不是第一个刚刚超过绝对阈值的波包。

### 5.5 三态结果

最终结果必须是三态：

```text
NORMAL  = 有效敲击 + 找到棒底 + 棒底前无异常反射
DEFECT  = 有效敲击 + 棒底前存在高置信度异常反射
INVALID = 敲击无效、无可靠反射、结果互相矛盾或信噪比不足
```

`INVALID` 提示重新敲击，不计入好坏结果。

## 6. 逐次敲击独立计分

根据计分表，“一次敲击记一次分”。因此每次敲击必须是一个完整、独立的
测量事件：

```text
本次触发
→ 本次256点波形
→ 本次有效性判断
→ 本次NORMAL / DEFECT / INVALID
→ 本次距离和置信度
→ 本次UART结果
```

不得使用前两次结果对当前这一击做多数投票，也不得使用多次距离的中位数
替代本次距离。否则会把不同计分事件混在一起，无法对应计分表中的单次成绩。

比赛允许多次敲击的价值是：

- 某一次 INVALID 后可以重新敲击，争取下一次有效得分；
- 可以展示系统的重复性；
- 可以在调试阶段统计稳定性；
- 不能用于修改赛前固化模板或改变本次判定阈值。

系统可以保留最近若干次结果用于旁路显示，例如：

```text
HIT 01: NORMAL
HIT 02: INVALID
HIT 03: DEFECT  506mm
```

但 VGA 主结果、UART 帧和蜂鸣提示必须始终对应当前这一击。历史统计不得
反馈到本次 `result_state` 和 `distance_mm`。

为了单次敲击也能稳定，必须加强：

1. 本次信号有效性门控；
2. 主冲击尾振隔离；
3. 多反射包识别；
4. 本次棒底时间归一化；
5. 明确的 INVALID/RETRY 输出。

## 7. 距离计算

### 7.1 找到本次棒底时

使用 Q12 定点比例：

```text
ratio_q12 = ((Tdef - T0) << 12) / (Tend - T0)
distance  = ratio_q12 × L_test_mm >> 12
```

现场棒 ±1mm 的影响可忽略。主要误差来自峰中心定位。

### 7.2 未找到棒底时

仅在缺陷反射非常明显时输出低置信度距离：

```text
distance = (Tdef - T0) × L_ref_mm / D_ref
```

VGA 应显示低置信度标志，不能与有棒底归一化的结果等价展示。

### 7.3 精度增强的优先级

剩余三天内的优先顺序：

1. 峰位置稳定；
2. 正常/缺陷/无效三态正确；
3. 每次敲击独立输出有效性和置信度；
4. 3 点重心或 1/4 点抛物线插值；
5. FFT。

FFT 不是当前最高优先级。它可在 PC 上辅助选择滤波频带，但不建议最后三天
再加入 FPGA 主判定链路。

## 8. VGA 含义

```text
黄色短线：主冲击中心 T0，距离起点
红色整线：缺陷反射中心 Tdef
紫色虚线：模板或本次识别出的棒底参考 Tend
绿色曲线：实际采集波形
```

若现场禁止校准，紫色线不能在运行中永久更新模板。它可以：

- 在找到本次棒底时，临时显示本次 `Tend`；
- 未找到棒底时，显示赛前固化的 `D_ref` 预测位置。

## 9. 三天执行安排

### 第 1 天：恢复可靠采集，建立数据集

上午：

- 修复触发噪声估计，先恢复轻敲也能显示波形；
- VGA 或 SignalTap 显示/记录当前触发阈值；
- 验证 20 次正常敲击至少 19 次触发；
- 静置、脚踩、碰桌面不得触发。

下午：

- 测量并记录自有棒实际长度；
- 固定传感器、锤头、敲击位置和平滑状态；
- 完成正常棒、缺陷棒、干扰数据采集；
- 当天结束后冻结硬件连接。

### 第 2 天：离线模板与规则回放

上午：

- PC 脚本完成波形对齐、幅值归一化、包络和反射包提取；
- 生成正常模板中位数和 MAD；
- 确定触发阈值、反射能量阈值、宽度范围和时间窗口。

下午：

- 用所有已采数据离线盲测；
- 再把确定的定点常数和规则写入 FPGA；
- 使用 UART 数据回放测试 RTL，不只使用人工合成波形。

当天结束条件：

- 参数冻结；
- 不再新增 FFT、复杂 FIR 或大规模界面功能。

### 第 3 天：盲测、回归和备份

上午：

- 随机打乱正常/缺陷棒，操作者不知道标签；
- 每根棒按比赛流程敲击；
- 统计触发率、误报、漏报、无效率和距离误差。

下午：

- 只修复明确 BUG，不再凭个别波形调整参数；
- 完整 Quartus 编译和全部仿真；
- 保存已验证 SOF、JIC、源码、参数表、UART 上位机；
- 准备“稳定版”和“低阈值应急版”两套烧录文件。

## 10. 冻结验收标准

至少满足：

| 项目 | 最低标准 |
|---|---|
| 正常敲击触发 | 20 次中至少 19 次 |
| 静止误触发 | 60 秒内 0 次 |
| 脚踩/碰桌面 | 不显示为有效锤击 |
| 正常棒 | 不允许“无反射却判正常” |
| 缺陷棒 | 已知中部缺陷重复检测稳定 |
| 单击距离 | 每次独立输出，不使用历史结果修正 |
| 重复性测试 | 同一位置独立敲击5次，距离极差不超过2个采样点 |
| 无效测量 | 明确显示 RETRY，不参与好坏 |
| 编译时序 | Quartus 0 Error，所有时钟 TNS=0 |

## 11. 立即需要改动与暂缓项

优先改动：

1. 用 `noise_ema` 替代 `1024 点最大值 × 4` 的触发阈值；
2. 取消运行期间自动更新棒底模板；
3. 把结果明确分成 NORMAL、DEFECT、INVALID；
4. 记录多个反射包并识别本次棒底；
5. 用真实 UART 波形做 RTL 回放。

暂缓：

- FPGA FFT；
- 复杂长阶 FIR；
- 中文字库；
- 多级菜单；
- 在线学习；
- 依赖现场按键的校准流程。

## 12. 代码修改方案（本节只描述，不在本方案阶段改代码）

### 12.1 `rtl/wave_trigger.v`

目标：先解决“锤击不能触发、没有新波形”。

计划修改：

1. 删除以 `noise_peak × 4` 直接形成触发阈值的做法；
2. 新增慢速绝对值平均 `noise_ema`；
3. 在疑似冲击期间冻结 `noise_ema`，防止锤击污染背景噪声；
4. 增加 `TH_MAX`，保证阈值不会超过轻敲主冲击能力；
5. 保留连续 2 点确认，避免单点尖峰触发；
6. 保留静默重新武装，但把静默计数与触发阈值分开验证；
7. 将 `noise_ema`、`threshold`、`magnitude` 接入 SignalTap。

验收：

- 轻、中、重敲均能触发；
- 脚踩、碰桌面、单点毛刺不触发；
- 一次敲击只采一帧；
- 触发后能自动恢复到 ARMED。

### 12.2 `rtl/wave_capture.v`

目标：保证模板、比赛和算法使用完全一致的数据长度。

计划修改：

1. 检测版本固定为 256 点；
2. 保留 32 点预触发；
3. 采集完成必须产生一个明确的 `cap_done`；
4. 无论检测结果如何，原始波形都允许显示和 UART 导出；
5. 检测器无效不得反过来阻止波形显示。

验收：

- 每次有效触发固定写入 256 点；
- 主冲击前始终有 32 点背景数据；
- 缺陷算法输出 INVALID 时，波形仍然可见。

### 12.3 `rtl/defect_analyzer.v`

目标：从“第一个过阈值峰”升级为“有效性 + 多反射包 + 三态判断”。

计划修改：

1. 保留主冲击尾振安静区；
2. 反射搜索不在找到第一个包后立即结束；
3. 最多保存 3～4 个反射候选；
4. 每个候选保存峰位置、峰幅、能量、宽度；
5. 根据赛前模板常数计算候选评分；
6. 在晚段窗口选择棒底候选；
7. 在棒底之前选择缺陷候选；
8. 输出：

```text
measurement_valid
result_state     // NORMAL / DEFECT / INVALID
impact_index
defect_index
bottom_index
confidence
```

9. 删除运行期间自动改变模板参考值的逻辑；
10. 所有模板参数由赛前数据生成，并作为只读定点常数综合。

验收：

- 无反射必须 INVALID；
- 冲击尾振不得作为缺陷；
- 正常棒底不得作为缺陷；
- 缺陷反射与棒底同时存在时，两者都能保留；
- 单点毛刺不得成为候选。

### 12.4 `rtl/defect_distance_calc.v`

目标：根据是否找到本次棒底选择距离算法。

计划修改：

模式 A，有本次棒底：

```text
distance =
    (defect_index - impact_index)
    × L_test_mm
    ÷ (bottom_index - impact_index)
```

模式 B，无本次棒底但缺陷置信度很高：

```text
distance =
    (defect_index - impact_index)
    × L_ref_mm
    ÷ D_ref
```

模式 B 必须输出低置信度标志。

为避免大组合除法器，继续使用顺序移位除法。若第 2 天数据回放稳定，再考虑
给峰位置增加 1/4 点定点位；在此之前保持整数点。

验收：

- 除数为 0 输出 INVALID；
- 距离不得超过棒长；
- ±1mm 棒长输入变化不会放大；
- 与 PC 参考模型逐帧一致。

### 12.5 `rtl/vga_dual_mode_top.v`

## 13. 300mm 与 700mm 缺陷的专门判断方案

### 13.1 理论位置

若正常棒底参考间隔约为 83 点，棒长约 1000mm，则：

```text
300mm 缺陷：83 × 300 / 1000 ≈ 25 点
700mm 缺陷：83 × 700 / 1000 ≈ 58 点
```

两者相差约 33 点，对应约 344μs。这个时间差远大于一个采样点，理论上容易
区分。即使现场棒长度相差 ±1mm，预计位置变化也远小于一个采样点。

如果两者在 VGA 上看起来接近，通常不是物理上无法区分，而是：

- 波形都被主冲击的大幅值压缩在同一显示比例下；
- 算法比较了波形形状，没有先对齐主冲击再比较到达时间；
- 300mm 反射落在主冲击尾振内；
- 当前主冲击状态最长持续 48 点，25 点附近的反射可能被当成主冲击一部分；
- 8 点包络进一步把近端反射与主冲击抹宽；
- 算法选择了同一个后续强峰，而没有选择真实缺陷反射。

因此不能靠肉眼比较整条曲线是否相似，也不能只比较最大峰幅值。需要比较
“主冲击对齐后，反射能量在哪个时间位置出现”。

### 13.2 推荐方法：正常模板抵消 + 短模板相关

这是三天内最稳妥的方法。

#### 第一步：对齐主冲击起点

`T0` 优先使用主冲击上升沿或波包能量中心，不使用容易随敲击力度漂移的
单个最大点。

每帧统一变换为：

```text
aligned[n] = envelope[T0 + n]
```

#### 第二步：幅值归一化

用主冲击峰或主冲击前 8～12 点能量归一化：

```text
normalized[n] = aligned[n] / impact_scale
```

这样轻敲和重敲的整体幅度不同不会直接改变判断。

#### 第三步：减去正常棒早期模板

赛前用多次正常棒数据生成主冲击尾振模板 `normal_impact[n]`：

```text
residual[n] = normalized[n] - normal_impact[n]
```

300mm 缺陷的反射虽然与尾振重叠，但相对正常棒会在约 25 点附近产生额外
残差；直接设置 48 点盲区会把这部分信息全部丢掉。

#### 第四步：短模板相关

从缺陷反射波包中截取约 8～16 点的短模板 `reflect_tpl[k]`，计算：

```text
score[t] = Σ residual[t+k] × reflect_tpl[k]
```

为了节省 FPGA 资源，可以把模板量化为：

```text
-1、0、+1
```

这样相关器只需要加减法，不需要通用乘法器。

#### 第五步：分窗口搜索

启动参考 83 点时，建议先使用宽窗口：

```text
近端窗口：18～35 点，覆盖约 215～420mm
远端窗口：48～70 点，覆盖约 580～845mm
棒底窗口：72～100 点
```

定义：

```text
S_near = 近端窗口最大相关分数
S_far  = 远端窗口最大相关分数
```

判断示例：

```text
S_near > 门限，且明显大于 S_far → 近端缺陷，约300mm
S_far  > 门限，且明显大于 S_near → 远端缺陷，约700mm
二者均低                         → NORMAL 或 INVALID
二者接近                         → INVALID，避免强行误判
```

最终距离使用相关峰的位置，不使用窗口中心。

### 13.3 更简单的三天应急方案：残差窗口能量

如果没有时间实现相关器，可以先计算：

```text
E_near = Σ abs(residual[n])，n=18～35
E_far  = Σ abs(residual[n])，n=48～70
```

然后比较归一化能量：

```text
E_near / E_impact
E_far  / E_impact
```

窗口能量法的定位精度不如相关法，但比“第一个过阈值峰 + 48点盲区”可靠，
而且只需要绝对值和累加器。

推荐顺序：

1. 先在 PC 上用已有或当天采集的 300mm、700mm 波形验证两个窗口；
2. 如果窗口能量已经完全可分，FPGA 先实现能量法；
3. 如果两类能量有重叠，再升级为短模板相关；
4. 不建议为这个问题加入 FFT，因为普通 FFT会丢失反射发生的时间位置。

### 13.4 对现有检测逻辑的修改边界

现有参数：

```text
MIN_IMPACT_POINTS = 12
MAX_IMPACT_POINTS = 48
8点绝对值滑动平均包络
```

不能继续把 `MAX_IMPACT_POINTS=48` 当成绝对搜索盲区。推荐改为两条并行支路：

```text
支路A：主冲击状态机
       用于确定冲击是否有效、何时进入远端普通反射搜索

支路B：模板残差近端检测
       从约第12点开始检查18～35点窗口
       专门检测被主冲击尾振覆盖的近端缺陷
```

两条支路最后合并候选。这样既不会因缩短主冲击状态而大量误报尾振，也不会
丢失 300mm 附近的真实反射。

检测包络建议：

- 触发和 VGA 原始波形链路保持不变；
- 普通远端搜索可继续使用 8 点包络；
- 近端残差检测使用 3～4 点包络，减少时间展宽；
- PIN_59 的显示平滑开关不能改变检测模板所使用的固定滤波。

### 13.5 必须采集的数据

至少采集：

| 类型 | 数量 |
|---|---:|
| 正常棒 | 20 次 |
| 300mm 缺陷，轻/中/重敲 | 各 10 次 |
| 700mm 缺陷，轻/中/重敲 | 各 10 次 |
| 脚踩、碰桌面、空敲 | 各 10 次 |

把数据随机分成两半：

- 前一半确定模板和阈值；
- 后一半只能验证，不能继续调参数。

验收时分别统计：

```text
300mm → 300mm 命中率
300mm → 700mm 误判率
700mm → 700mm 命中率
700mm → 300mm 误判率
NORMAL → 缺陷误报率
INVALID 比例
```

只看几条代表性波形不能证明算法有效。
