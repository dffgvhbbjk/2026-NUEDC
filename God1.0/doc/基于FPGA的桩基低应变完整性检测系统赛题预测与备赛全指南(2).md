# 基于FPGA的桩基低应变完整性检测系统 — TI杯赛题预测

## 一、赛题名称

**基于FPGA的桩基完整性检测系统**

---

## 二、赛题任务

### 任务A：采集系统搭建（硬件构建）

**要求**：
1. 使用IEPE加速度传感器（50G量程），通过LM334恒流源供电，构建完整信号链路
2. 使用PCM1808（24位ADC）完成信号采集，采样率可调（10kHz~96kHz，PCM1808上限96kHz；本设计固定48kHz）
3. 运放OPA2690完成信号调理，放大倍数可调（10倍~100倍）
4. 信号链路的等效输入噪声≤10μVrms
5. 采集数据稳定无丢点，连续采集时长≥10s

**难点**：
- 微弱信号（mV级）的噪声抑制
- 高频采样时的数据完整传输
- 多增益档位的精确控制

**实现注意**：
- IEPE 传感器输出带 ~10V 直流偏置，运放前必须 AC 耦合（隔直）并将偏置调到 ADC 输入范围中点，否则直接饱和——模拟评审必问
- "连续采集 10s" 指**实时流过处理**：48kHz×10s×24bit≈1.4MB，片上 RAM 仅 276kbit 存不下，答辩时勿承诺"存储 10s 原始波形"

---

### 任务B：时域分析与缺陷定位（核心算法）

**要求**：
1. **自动触发**：敲击后自动识别激振起始点，触发精度≤0.5ms（⚠️ 必须在 FIR **之前**的原始数据上检测：151阶FIR@48kHz群延迟≈1.56ms，滤波后检测直接超标）
2. **数字滤波**：实现FIR低通滤波器，通带截止频率1kHz~20kHz可调（上限受采样率约束 ≤fs/2，采样率低于40kHz时通带范围同步收窄），阻带衰减≥40dB，滤波器阶数可配置（32~256阶；当前实现为151阶固定）
3. **反射峰检测**：自动检测前3个反射波的峰值位置与幅值（当前实现仅入射峰+桩底反射峰，前3峰需扩展）
4. **波速标定**：在已知桩长的试件上自动标定应力波波速
5. **缺陷深度计算**：基于反射波到达时间，计算缺陷深度，相对误差≤3%（⚠️ 单样本时间分辨率≈4cm，浅缺陷必须做峰值亚样本插值，见5.5节）
6. **桩长测量**：基于桩底反射波，测量桩长，相对误差≤2%

**难点**：
- 高精度FIR滤波器的实时计算（48kHz采样率下）
- 弱反射峰的信噪比提升
- 多反射峰的自动识别与筛选

**关键路径**：桩长2%/深度3%精度全部依赖任务B.4波速标定先完成（混凝土波速天然散布±10%，不标定直接超差）——备赛时标定功能必须第一个闭环

---

### 任务C：频域分析与缺陷分类（高级算法）

**要求**：
1. **FFT实时计算**：实现1024点/2048点FFT，帧率≥40Hz（48kHz无重叠上限46.9Hz；50%重叠滑窗可达~90Hz等效帧率）
2. **频谱显示**：VGA显示实时频谱，频率分辨率≤100Hz
3. **固有频率提取**：自动提取前3阶桩身固有频率（⚠️ 桩5~20m对应f₁≈47~190Hz，46.9Hz分辨率误差达25~50%，须加谱峰抛物线插值至~1Hz级，或仅作定性特征）
4. **缺陷特征分析**：
   - 提取反射波的相位特征（正/负）
   - 提取反射波的幅值衰减率
   - 提取频域谐振峰偏移量
5. **缺陷自动分类**：
   - 缩径缺陷（同相反射）
   - 扩径缺陷（反相反射）
   - 断桩缺陷（强反射+高频谐振）
   - 蜂窝缺陷（漫反射+能量衰减）
6. **完整性等级评定**：输出Ⅰ/Ⅱ/Ⅲ/Ⅳ类桩评定

**难点**：
- FFT的实时性与资源优化
- 多特征融合的缺陷分类算法
- 分类准确率≥85%

---

### 任务D：多通道采集（系统扩展）

**要求**：
1. 实现2路IEPE传感器同步采集
2. 两路采样时钟同步误差≤10ns
3. 实现两路信号互相关分析（两路平均物理上限3dB；结合4次敲击相干平均可达≥9dB）
4. 基于两路信号到达时间差，实现缺陷横向定位
5. 支持一路参考信号输入（用于环境噪声对消）

**难点**：
- 多通道时钟同步
- 互相关算法的硬件实现
- 实时数据对齐

---

### 任务E：VGA波形可视化（人机交互）

**要求**：
1. **时域波形显示**：
   - 显示完整的回波时域波形
   - 自动标注激振触发点（红色三角标记）
   - 自动标注前3个反射峰位置（蓝色标记）
   - 显示触发电平线（可调节）
2. **频谱显示**：
   - 显示FFT幅值频谱
   - 自动标注前3阶固有频率
3. **信息叠加**：
   - 显示当前采集状态
   - 显示计算出的缺陷深度/桩长
   - 显示缺陷类型和完整性等级
4. **交互控制**：
   - 暂停/继续显示
   - 波形缩放（×1/×2/×4）
   - 模式切换（时域/频域/双屏）
5. **摄像头图像叠加**：
   - 显示OV5640实时图像
   - 在图像上叠加检测结果

**难点**：
- VGA 800×600分辨率的实时刷新
- 多层信息的叠加显示
- 交互控制的响应速度

---

### 任务F：摄像头辅助（视觉增强）

**要求**：
1. OV5640配置与驱动：
   - I2C (SCCB协议) 初始化配置
   - DVP接口数据采集（640×480 @ 30fps）
   - 帧缓存与显示（EP4CE6 内存受限：80×60 整帧缓存 + 8倍上采样；全分辨率需外部SDRAM）
2. **敲击有效性判定**：
   - 实时显示敲击区域
   - 判断敲击位置是否在有效区域
   - 自动过滤偏敲数据
3. **触发时刻辅助校验**：
   - ⚠️ 摄像头30fps一帧33ms，无法"精确标定"锤头接触瞬间（与0.5ms触发精度差66倍）
   - 实际作用：粗校验敲击是否发生/是否偏敲；精触发仍由ADC阈值检测完成
4. **结果叠加显示**：
   - 在摄像头画面上叠加检测结果
   - 显示缺陷位置、深度、类型
   - 显示桩体编号（编号录入：按键循环加减，系统无键盘）

**难点**：
- 摄像头数据的实时处理（30fps）
- 图像识别算法（敲击位置判定）
- 图像叠加的Alpha混合

```
ADC采集 → 异步FIFO → 触发检测 → FIR滤波 → 峰值检测 → 深度计算 → 数码管
```

> ΔT 相消不受影响）。

## 五、各模块详细任务

### 5.1 ADC采集模块

**功能**：
- 驱动PCM1808 ADC芯片
- 24位数据采集，采样率10kHz~96kHz可调（本设计固定48kHz）
- 双通道同步采集
- 数据FIFO缓冲

**输入**：
- ADC数字音频接口信号（BCK/LRCK/DATA）
- 采样率配置参数

**输出**：
- 24位采样数据
- 数据有效标志
- 采样时钟

**关键参数**：
| 参数 | 值 |
|------|-----|
| 采样率 | 10kHz ~ 96kHz (本设计固定 48kHz) |
| 数据位宽 | 24位 |
| 通道数 | 2 |
| FIFO深度 | 256×24位 (DCFIFO) |
| 时钟同步误差 | ≤10ns |

---

### 5.2 触发检测模块

**功能**：
- 自动检测敲击激振起始点
- 自适应阈值计算
- 上升沿检测
- 触发时刻标定（与摄像头融合）

**算法**：
1. 计算信号基线（滑动窗口均值，N=100）
2. 计算噪声标准差
3. 设置阈值 = 基线 + 5×标准差
4. 检测连续3点超过阈值
5. 触发后预采集100点，后采集≥1200点（25ms；500点仅10.4ms，20m桩底反射10.5ms即溢出，40m桩需21ms）
6. ⚠️ 触发检测用 FIR 之前的原始数据（滤波后检测自带1.56ms群延迟，吃掉0.5ms精度指标）

**关键参数**：
| 参数 | 值 |
|------|-----|
| 触发精度 | ≤0.5ms |
| 自适应时间 | 100ms |
| 预采集点数 | 100 |
| 后采集点数 | ≥1200 (25ms) |

---

### 5.3 FIR低通滤波器

**功能**：
- 滤除高频噪声和工频干扰
- 通带截止频率可调（1kHz~20kHz）
- 滤波器阶数可配置（32~256阶）
- 阻带衰减≥40dB

**实现方式**：
- 串行 MAC 复用（当前实现：FIR II IP，151阶，实测仅占1个9-bit乘法器）
- 系数ROM + 移位累加
- ⚠️ 阶数与过渡带耦合：1kHz截止@48kHz需≥100阶才能满足40dB阻带，32阶仅适用于高截止频率档

**关键参数**：
| 参数 | 值 |
|------|-----|
| 阶数 | 32~256阶可调 |
| 通带截止 | 1kHz~20kHz |
| 阻带衰减 | ≥40dB |
| 通带纹波 | ≤1dB |
| 计算延迟 | ≤1ms |

---

### 5.4 FFT频谱分析

**功能**：
- 1024点/2048点FFT
- 帧率≥50Hz
- 频谱显示
- 固有频率提取

**实现方式**：
- Radix-4 SDF结构
- 5级流水线
- 1个复数乘法器 + 1个蝶形运算器
- CORDIC算法计算幅值

**关键参数**：
| 参数 | 值 |
|------|-----|
| FFT点数 | 1024/2048 |
| 帧率 | ≥40Hz (48kHz无重叠上限46.9Hz；50%重叠~90Hz) |
| 频率分辨率 | ≤100Hz (46.9Hz@1024点) |
| 谱峰频率精度 | ~1Hz (抛物线插值后，固有频率提取必需) |
| 幅值精度 | 12位 |
| 窗函数 | 汉宁窗 |

---

### 5.5 反射峰检测

**功能**：
- 一阶导数过零点检测
- 自动识别前3个反射峰
- 提取峰值位置、幅值、相位

**算法**：
1. 计算一阶导数 data[n] - data[n-1]
2. 正→负过零点 = 峰值
3. 负→正过零点 = 谷值
4. 峰值幅值 = data[peak] - baseline
5. 峰值排序，取前3个
6. ⚠️ 峰值位置**亚样本插值**（抛物线/质心法）：单样本≈4cm，这是浅缺陷3%精度指标的唯一达标途径

**关键参数**：
| 参数 | 值 |
|------|-----|
| 检测点数 | 前3个反射峰 |
| 幅值精度 | 1% |
| 时间精度 | ≤0.1ms |
| 误检率 | ≤5% |

---

### 5.6 缺陷分类器

**功能**：
- 基于时域+频域特征融合
- 自动判断缺陷类型
- 完整性等级评定

**特征提取**：
| 特征 | 来源 | 维度 |
|------|------|------|
| 反射波相位 | 时域 | 正/负 |
| 反射波幅值 | 时域 | 归一化 |
| 衰减率 | 时域 | 比值 |
| 谐振频率 | 频域 | 3阶 |
| 频移量 | 频域 | 偏移值 |

**分类规则**：
| 缺陷类型 | 相位 | 幅值 | 频率特征 |
|---------|------|------|---------|
| 缩径 | 同相 | 中 | 频率降低 |
| 扩径 | 反相 | 中 | 频率升高 |
| 断桩 | 同相 | 强 | 高频谐振 |
| 蜂窝 | 漫反射 | 弱 | 能量衰减 |

---

### 5.8 OV5640摄像头模块

**功能**：
- SCCB（I2C）初始化配置
- DVP接口数据采集
- 帧缓存管理
- 图像叠加显示

**SCCB配置**：
```verilog
// 关键寄存器配置 (完整表见 rtl/ov5640_init.v, 共 111 个寄存器)
// 0x3103 -> 0x11         (系统时钟来自 PAD)
// 0x3008 -> 0x82         (软件复位, 复位后须延时 ≥20ms 再配置)
// 0x3808/0x3809 -> 0x02/0x80  (DVPHO 输出宽度 = 640)
// 0x380a/0x380b -> 0x01/0xE0  (DVPVO 输出高度 = 480)
// 0x4300 -> 0x6f         (RGB565 输出)
// 0x501f -> 0x01         (ISP 输出 RGB 格式)
```

**DVP时序**：
```
VSYNC: 帧同步（本项目配置为低有效：下降沿 = 帧开始，上升沿 = 帧结束）
HREF: 行有效（高电平有效）
PCLK: 像素时钟（每个上升沿输出1字节）
DATA: 8位并行数据（2个PCLK输出1个RGB565像素）
```

**帧缓存（受 EP4CE6 内存硬约束，必须降分辨率）**：
```
- 整帧 640×480×16bit = 4,915,200 bit, 需要 ~534 个 M9K
  (M9K 单块 = 9,216 bit), 而 EP4CE6 全片仅 30 个 → 整帧不可能
- 可行方案: OV5640 ISP 下采样输出 80×60, 整帧双口 RAM 缓存
  (80×60×16 = 76,800 bit ≈ 9 个 M9K), VGA 端 8 倍最近邻
  上采样回 640×480 显示
- ⚠️ 16 行循环行缓存方案: VGA 60Hz 读 > 摄像头 30Hz 写,
  读写同 slot 冲突 → 整屏水平撕裂, 已定性为不可用方案
```

### 5.9 互相关模块

**功能**：
- 两路信号互相关分析
- 延迟估计
- 信噪比提升

**算法**：
```
Rxy[τ] = Σ x[n] × y[n-τ]
τ_max = argmax(Rxy[τ])
延迟 = τ_max / fs
信噪比提升：两路独立噪声平均 = 3dB (物理上限, 原公式10log10(1+ρ)错误)
进一步：N次敲击相干平均 → 10×log10(N), 4次≈6dB, 8次≈9dB
```

**关键参数**：
| 参数 | 值 |
|------|-----|
| 相关点数 | 512点 |
| 延迟精度 | 1采样点（更高需插值） |
| 信噪比提升 | ≥3dB (两路平均) / ≥9dB (叠加4次敲击相干平均) |
| 计算延迟 | ≤10ms |

## 七、关键算法实现方案

### 7.1 FIR滤波器（151阶，当前实现）

```verilog
// 串行复用方案 (与项目 FIR II IP 一致):
// 151阶, 单 MAC 时分复用
// 乘累加速率 = 48kHz × 151 ≈ 7.3MHz
// sys_clk = 50MHz >> 7.3MHz → 裕量充足
// 实测仅占用 1 个 9-bit 乘法器 (2026-07-21 fit.summary)
```

### 7.2 FFT（1024点 Radix-4）

```verilog
// Radix-4 SDF结构
// 5级流水线 (log4(1024) = 5)
// 每级1个复数乘法器 + 1个蝶形运算器
// 单样本/周期吞吐: 一帧 ≈ 1024 + 流水线填充 ≈ ~1300 周期
// sys_clk = 50MHz → 一帧 ~26µs, 帧率 ~38kHz >> 50Hz
```

### 7.3 触发检测

```verilog
// 自适应阈值触发
// 基线估算：滑动窗口均值（前100点）
// 阈值 = 基线 + 5×噪声标准差
// 上升沿检测：连续3点超过阈值
// 触发后预采集100点，后采集500点
```

### 7.4 反射峰识别

```verilog
// 一阶导数过零点检测
// 导数 = data[n] - data[n-1]
// 正→负过零点 = 峰值
// 负→正过零点 = 谷值
// 峰值幅值 = data[peak] - baseline
// 峰值排序 → 取前3个
```
