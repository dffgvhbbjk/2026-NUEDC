# P3 缺陷识别与距离定位实施方案

## 1. 目标

在现有 PCM1808、FIFO、触发采集、波形 RAM 和 VGA 显示均稳定的基础上，实现：

1. 基本要求（3）：自动输出正常/异常标志。
2. 发挥部分（2）：输出缺陷距检测物顶部的距离，单位为 mm。
3. 发挥部分（3）：兼容塑料锤头和金属锤头。
4. 保持现有 64/128/256 点采集、VGA 波形显示和 UART 原始数据导出功能。

比赛对象为约 1m 长、直径 60mm 的尼龙棒。异常棒在中间某处存在断裂。

---

## 2. 官方参考算法结论

官方代码采用两级 RAM：

- 第一级 `ADC_RAM`：连续保存 ADC 数据。
- 第二级 `ram_vga`：保存触发后回读的显示波形。

官方缺陷判断并没有真正定位反射峰，而是：

1. 判断最近 5 点是否连续单调上升；
2. 统计这种状态的上升沿和下降沿数量；
3. 边沿数量达到 11 次时判为异常。

官方距离计算为：

```text
result = 某段单调上升状态持续时间 × 15
```

该方法属于针对样品调出的经验算法，存在以下问题：

- 固定阈值，不能很好适应敲击力度和不同锤头；
- 容易把主冲击回摆当作反射；
- 没有区分缺陷反射和底端反射；
- 距离公式缺少采样率、波速和往返传播关系；
- 噪声或平滑设置变化后，波形单调段数量会改变。

因此本项目只把“波包数量”作为辅助特征，不直接照搬官方判定。

## 3. 总体架构

```text
PCM1808 左声道
      |
I2S接收 + 异步FIFO
      |
基线扣除 + 自适应触发
      |
可旁路三点平滑
      |
      +----------------------+
      |                      |
wave_capture             defect_analyzer
      |                      |
512×16波形RAM          缺陷标志/峰位置
      |                      |
VGA波形显示          defect_distance_calc
                             |
                       距离(mm)/置信度
                             |
              +--------------+--------------+
              |              |              |
          VGA字符显示      缺陷标线       蜂鸣器提示
```

`defect_analyzer` 直接监听写入波形 RAM 的同一组有效数据，优先使用平滑链路中的 24 位数据。这样：

- 不占用 VGA 的 RAM 读端口；
- 不增加 RAM 读写仲裁；
- 保留 24 位幅值精度；
- 分析样点与显示样点保持一一对应。

## 4. 实测波形带来的算法调整

实测缺陷波形表现为多组宽的正负波包，不是孤立的单样点尖峰。因此不能简单地搜索第一个局部极大值。

应先生成包络：

```text
abs[n] = |sample[n]|

env[n] = (
    abs[n] + abs[n-1] + ... + abs[n-7]
) / 8
```

8 点滑动平均只需要加法、减法和右移，不使用硬件乘法器。

推荐采用滑动和：

```text
sum8[n] = sum8[n-1] + abs[n] - abs[n-8]
env[n]  = sum8[n] >> 3
```

## 5. 主冲击波包识别

### 5.1 主峰

从 `smooth_trig` 开始，对随后约 24～32 个有效样点搜索最大包络，得到：

```text
impact_peak
impact_peak_index
```

主冲击的第一个负谷和紧随其后的正峰可能属于同一个波包，不能将正峰误判成缺陷反射。

### 5.2 动态盲区

不使用固定的“触发后跳过 8 点”，改为动态判断主波包结束。

主波包结束条件建议为：

```text
env < impact_peak / 4
```

并连续满足 6～8 个样点。

同时增加最大盲区限制，例如 48 点，避免波形持续振荡导致永远不进入缺陷搜索阶段。

---

## 6. 反射波包检测

主波包结束后进入反射搜索状态。

### 6.1 自适应阈值

```text
reflect_threshold = max(
    MIN_REFLECT_THRESHOLD,
    pretrigger_noise × 6,
    impact_peak / 10
)
```

其中：

- `pretrigger_noise`：触发前样点包络或绝对值的最大值；
- `impact_peak/10`：按本次敲击强度归一化；
- `MIN_REFLECT_THRESHOLD`：防止极静环境下阈值过低。

具体比例需要使用正常棒和缺陷棒原始 ADC 数据标定。

### 6.2 波包合并

单个反射波包内部可能包含多个正负峰。若相邻包络峰间隔小于 10～16 点，则合并为同一个波包。

每个波包记录：

```text
packet_start
packet_end
packet_peak
packet_peak_index
packet_energy
```

第一版可以仅保存峰值和峰位置，不保存全部波包。

### 6.3 有效反射条件

建议同时满足：

1. 包络超过 `reflect_threshold`；
2. 连续超过阈值至少 2～3 点；
3. 与上一个波包间隔达到最小间距；
4. 位于主波包结束之后；
5. 位于正常棒底端反射窗口之前，才作为缺陷候选。

## 7. 正常/异常判断

### 7.1 正常棒校准

复位已经迁移至板载 PIN_25，空闲的外接 PIN_53 推荐作为“正常棒校准键”。

校准步骤：

1. 输入实测棒长 `rod_length_mm`，默认可设为 1000mm。
2. 放置正常尼龙棒。
3. 完成一次质量良好的敲击采集。
4. 按下 PIN_53。
5. 保存正常棒底端反射参数：

```text
end_ref_index
end_ref_peak
normal_early_peak
```

校准数据先保存在寄存器中，重新上电后需要再次校准。后续如有需要，再增加 EEPROM/Flash 保存。

### 7.2 判定规则

```text
若在 end_ref_index 之前存在可靠的强反射波包：
    defect_flag = 1
否则：
    defect_flag = 0
```

为了减少误判，建议增加底端窗口：

```text
END_MARGIN = 6～10 点

缺陷搜索范围：
    主波包结束位置 ～ end_ref_index - END_MARGIN
```

可增加辅助判据：

- 缺陷候选峰明显高于正常棒同一区域峰值；
- 波包数量明显多于正常棒；
- 正常底端反射消失或明显减弱。

### 7.3 输出

```verilog
output reg        result_valid;
output reg        defect_flag;
output reg [8:0]  defect_peak_index;
output reg [15:0] defect_peak_value;
output reg [7:0]  confidence;
```

`confidence` 可用以下比例近似：

```text
confidence = defect_peak / reflect_threshold
```

第一版也可以暂不输出置信度。

## 8. 缺陷距离计算

### 8.1 推荐：正常棒比例校准

定义：

```text
T0   = 主冲击波包中心位置
Tend = 正常棒底端反射波包中心位置
Tdef = 缺陷反射波包中心位置
L    = 实测棒长，单位 mm
```

则：

```text
distance_mm =
    (Tdef - T0) × L
    ÷ (Tend - T0)
```

该公式能抵消：

- 尼龙材料波速差异；
- 棒长不是精确 1m；
- PCM1808 实际采样率误差；
- 触发和滤波的固定延迟；
- 传感器安装造成的固定延迟。

### 8.2 备用：波速公式

未校准时可以使用：

```text
distance_mm =
    sample_delta × velocity_mps × 1000
    ÷ (2 × sample_rate_hz)
```

当前采样率约 95.88kHz。尼龙实际波速受配方、温度和结构影响，不建议只使用固定波速。

### 8.3 FPGA 定点实现

最大计算量约为：

```text
256 × 1200 = 307200
```

使用 20 位无符号寄存器即可。

新增顺序除法器：

```verilog
module defect_distance_calc (
    input  wire        clk,
    input  wire        rst_n,
    input  wire        start,
    input  wire [8:0]  defect_delta,
    input  wire [8:0]  end_delta,
    input  wire [11:0] rod_length_mm,
    output reg         done,
    output reg  [11:0] distance_mm
);
```

除法使用移位减法，约 20 个 40MHz 时钟完成，对系统实时性没有影响。

## 9. 理论距离分辨率

当前采样率约 95.88kHz。若尼龙有效传播速度约 2000～2600m/s，则整数样点对应：

```text
约 10.4～13.6mm/点
```

预计：

- 整数峰定位：约 ±1 点，即约 ±10～14mm；
- 3 点重心或抛物线插值：理论上可达到约 3～7mm；
- 实际误差还受敲击位置、传感器固定方式、裂缝宽度和材料差异影响。

第一版先使用整数样点定位。基本功能稳定后，再增加 1/4 点插值。

## 15. 仿真测试计划

### 15.1 缺陷判断

- 只有主冲击，无后续反射：正常；
- 正常底端反射：正常；
- 底端反射前增加强波包：异常；
- 主冲击后立即回摆：不得误判为缺陷；
- 单点噪声尖峰：不得误判；
- 连续多个缺陷反射：报告第一个可靠缺陷；
- 塑料锤低幅值与金属锤高幅值均能判断。

### 15.2 距离

- 缺陷位于 250、500、750mm 的合成数据；
- 棒长为 980、1000、1020mm；
- 除数为零时输出无效，不允许锁死；
- 最大距离不超过棒长；
- 结果误差不超过整数运算预期。

### 15.3 系统回归

必须继续通过：

- PCM1808 I2S 接收；
- 异步 FIFO；
- 触发与重新布防；
- 64/128/256 点采集；
- 平滑旁路；
- 24 位 UART 导出；
- VGA 波形显示；
- HOLD 超时恢复；
- Quartus 全编译及时序分析。

## 16. 分阶段实施顺序

### 阶段 A：离线数据分析

1. 收集正常/缺陷原始 ADC 数据；
2. 使用脚本绘制绝对值包络；
3. 确定主波包宽度；
4. 确定缺陷反射和底端反射窗口；
5. 确定阈值比例和最小波包间距。

### 阶段 B：FPGA 缺陷判断

1. 编写 `defect_analyzer.v`；
2. 输出正常/异常和缺陷样点位置；
3. 用仿真和 SignalTap 验证；
4. 暂时通过蜂鸣器或调试信号输出结果。

### 阶段 C：校准与距离

1. 将 PIN_53 设置为校准键；
2. 保存正常棒底端反射位置；
3. 编写定点距离计算模块；
4. 对照游标卡尺/卷尺实测距离。

### 阶段 D：VGA 输出

1. 编写数字和必要字母字模；
2. 显示正常/异常；
3. 显示距离；
4. 在波形上叠加缺陷峰竖线。

### 阶段 E：双锤头标定

1. 分别测试塑料锤和金属锤；
2. 调整归一化阈值；
3. 验证不同敲击力度；
4. 固化最终默认参数。

## 17. 验收标准

### 基本要求（3）

- 正常棒连续敲击至少 10 次，无明显误报；
- 缺陷棒连续敲击至少 10 次，能够稳定输出异常；
- 敲击力度变化时仍能正常判断；
- 检测结束后系统能自动重新布防，不永久卡在 HOLD。

### 发挥部分（2）

- 能输出缺陷距顶部的毫米数；
- 输出距离不超过棒总长；
- 重复敲击结果波动建议控制在 ±2 个样点内；
- 目标初版误差：约 ±15～30mm；
- 完成插值和机械安装优化后，争取达到约 ±10mm。

### 发挥部分（3）

- 塑料锤和金属锤均能识别缺陷；
- 不依赖写死的绝对幅值阈值；
- 两种锤头测得的缺陷距离差异控制在可接受范围内。

## 19. 新算法（数据驱动）：冲击回波自相关 + LDA 线性判别

> 本节记录 2026 版对 §3–§18 旧包络波包法的替代。旧法在实测数据上检出率仅
> 30–50%、距离误差 ±50–100mm；新算法基于 `God3.0/data` 全量约 1.6 万次敲击
> 离线分析总结的规律推导，已在 ModelSim 中与 Python 定点模型逐比特对齐。

### 19.1 数据规律

- 好棒基波周期约 96–98 采样点（≈983Hz），坏棒 100–107 点（890–936Hz）：
  裂缝改变棒的刚度，从而改变固有频率。
- 不同缺陷位置在冲击后信号的**自相关曲线**上留下独特“指纹”：
  - `d800`（距端 800mm）：T/2 处深谷；
  - `d695`：T/3 处宽负区；
  - `d307`：曲线平坦、基波峰偏低；
  - `good`（正常棒）：整体平缓正值。

### 19.2 算法流水线（与 `tools/fpga_model.py` 逐比特一致）

1. 512 点采集帧内找 |x| 峰值位置 `imp`（主冲击）。
2. 有效性判定：`peak<MIN_PEAK` 或 `imp>=IMP_WIN`（二次弹跳/双击）或
   `imp+SKIP+SEGLEN>512` → 输出 INVALID（提示重敲）。
3. 自动缩放 `sh=max(0,bits(peak)-15)`，取冲击后 `s[i]=x[imp+16+i]>>>sh`（16 位，i=0..383）。
4. 整数自相关 `r[k]=Σ s[i]·s[i+k]`，`k=0` 及 `k=8..135`。
5. 二次缩放 `rsh=max(0,bits(r0)-30)`，`rs[k]=r[k]>>>rsh`（压到 31 位内）。
6. 打分 `score_c = Σ_{k=8}^{135} w_c[k]·rs[k] + w_c[128]·rs0`（Q12 岭回归 LDA 权重，5 类）。
7. `argmax(score)` → 类别；`top1-top2 < rs0·MARGIN_Q` → 低置信。
   类别 0=good(NORMAL)，1..4=d200/d307/d695/d800（DEFECT + 距离查表）。

**FPGA 只需乘累加 + argmax，无除法。**

### 19.4 RTL 实现与集成

- 模块 `rtl/defect_ac_classifier.v`（13 态状态机）：影子 RAM 1024×24（乒乓双 bank，
  镜像 `wave_capture` 写口）、seg RAM 512×16（true dual-port）、r RAM 256×48；
  自相关串行单乘法器、打分串行单乘法器、argmax 串行扫描。
- 权重表 `rtl/defect_lda_weights.vh`（Q12，5 类×129，由 `tools/fpga_model.py` 生成）。
  以**寄存器输出 case**（Intel 推荐 ROM 推断风格）综合为 M9K ROM，避免巨型 LUT 多路器。
- 周期约 46k 拍 @40MHz ≈ 1.15ms，远小于重武装静默期 ~85ms；与 `vga_clk` 同域，无 CDC。
- 顶层 `vga_dual_mode_top.v`：新分类器接影子写口
  (`buf_wr_en`/`buf_wr_addr`/`smooth_raw`) 与 `wave_cap_done`/`wave_disp_origin`/
  `wave_disp_len`/`capture_rearm_pulse`；其 `result_state`/`confidence`/`distance_mm`/
  `impact_index` 作为**最终判定**驱动 overlay 与 UART 结果字段。旧 `defect_analyzer`
  仅保留 VGA 波形红/紫标记线索引（display-only），`defect_distance_calc` 除法器已移除。
